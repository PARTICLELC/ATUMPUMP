# ATUMPUMP

ATUMPUMP is an open-source, unlimited-use market intelligence
and championship simulation platform designed for Termux.

## Unified Product

One installation provides:

- Market data services
- A-LIST championship game
- Pair intelligence and observation
- Live dashboards and leaderboards
- Service management
- Upgrade-safe database preservation

## Termux Installation

The public package repository and installation instructions
will be published with the first stable release.

Planned installation:

    pkg install atumpump

## Data Preservation

Existing databases, trading records, credentials and local
configuration are user-owned runtime data. They are not
included in public source releases or overwritten during upgrades.
